## 30 秒サマリ

- 背景は **生成り `#F4EFE5`**。参考イラストのサーモンピンクは使わない。
- 有彩色は **テラコッタ `#D96F4C`** の差し色のみ。1 画面に 2 箇所まで、面積 10% 以下。
- 線は **墨 `#23201D`** の細い均一線。影・グラデーション・立体表現はゼロ。
- 顔は描かない。人物は 8〜9 頭身、シルエットと姿勢で語る。
- ブランドシンボルは **ツバメ**。小さく、たまにだけ出す。
- 完了・達成だけ **マスタード `#F0B429`**。

## 生成後に必ずやること

生成 AI は色を必ず 5〜15% ずらすので、**カラーピッカーで実測して規定 HEX に総入れ替え**する。
ここをやらないと 100 点並べたときに絵柄が揃わない。
